Step 1 — Create Firebase project (free)
1. Go to console.firebase.google.com
2. Click "Add project" → name it anything (e.g. lovespace)
3. Disable Google Analytics → click Create project
Step 2 — Create a web app
1. In your project, click the </> (Web) icon
2. Give it a nickname (e.g. lovespace) → click Register app
3. You'll see a firebaseConfig object — copy the whole thing
Step 3 — Enable Realtime Database
1. In the left menu → Build → Realtime Database
2. Click "Create Database" → choose any location → click Next
3. Select "Start in test mode" → click Enable
